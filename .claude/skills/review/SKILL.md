## 코드 리뷰 수행

$ARGUMENTS에 대해 코드 리뷰를 수행하세요.

### 리뷰 관점
1. **정확성**: 로직 오류, 엣지 케이스 누락
2. **보안**: SQL 인젝션, XSS 등 OWASP Top 10 취약점
3. **성능**: 불필요한 쿼리, N+1 문제, 메모리 누수
4. **가독성**: 네이밍, 코드 구조, 주석 적절성
5. **테스트**: 테스트 커버리지, 누락된 테스트 케이스

### 출력 형식
- 심각도 표시: `[Critical]`, `[Warning]`, `[Suggestion]`
- 파일명:라인번호와 함께 구체적으로 지적
- 수정 제안 코드 포함
