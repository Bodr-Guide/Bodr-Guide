## 서브에이전트 기반 개발

$ARGUMENTS 작업을 서브에이전트에게 위임하고 결과를 리뷰하세요.

### 프로세스

1. **작업 분해** — 전체 작업을 독립적인 하위 작업으로 분해
2. **위임** — 각 하위 작업을 서브에이전트(Task 도구)에게 할당
   - 병렬 실행 가능한 작업은 동시에 위임
   - 각 서브에이전트에게 명확한 컨텍스트와 기대 결과 전달
3. **리뷰** — 서브에이전트 결과를 검증
   - 코드 품질, 일관성, 프로젝트 컨벤션 준수 여부 확인
   - 서브에이전트 간 결과의 통합성 확인
4. **통합** — 검증된 결과를 통합하여 최종 산출물 완성

### 규칙

- 서브에이전트에게 충분한 컨텍스트를 제공
- 결과를 무조건 신뢰하지 않고 반드시 리뷰
- 통합 후 전체 테스트 실행으로 검증
